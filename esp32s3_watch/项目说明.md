# ESP32-S3 智能手表 —— 项目说明

一个用来学习和面试演示的智能手表项目（参考 OV-Watch 的功能设计，但用 ESP32-S3 + ESP-IDF 实现）。

## 快速上手（3 条命令）

```powershell
cd D:\esp32\esp32s3_watch
idf.py build
idf.py -p COM8 flash monitor     # COM8 换成你的串口号（插拔后会变），Ctrl+] 退出
```

> 需要先双击桌面 `IDF_v6.1-beta1_Powershell` 打开配置好 IDF 环境的终端。

### 交互设计（约定）

```
表盘（根页面）：点按 -> 菜单；左右滑都不动作（边界）
菜单/秒表/关于：右滑 35px -> 返回上一页；底部 "< BACK" 点按 -> 返回
秒表：点按屏幕 = 开始/暂停；底部 "RESET" = 清零；"< BACK" = 返回
      BOOT 短按 = 开始/暂停；BOOT 长按 = 清零并返回
```

### 接线（重要）

```
屏幕 P183B001-V4-CTP（ST7789P3 显示 + CST816T 触摸）
  显示：SCLK GPIO12  MOSI GPIO11  CS GPIO10  DC GPIO13  RST GPIO14
  触摸：SCL  GPIO9   SDA  GPIO8   RST GPIO6   INT GPIO7
  PWR/BLK 脚必须接 3V3（背光供电，不接屏幕全黑）
板载 WS2812 数据脚：GPIO48      BOOT 键：GPIO0
```

## 调试笔记（踩过的坑，面试可以讲）

1. **LVGL 的 `LV_EVENT_PRESSING` 不会发给输入设备(indev)本身**，只发给"被按下的控件"。
   所以滑动判断要挂在**页面屏幕对象**上：
   `lv_obj_add_event_cb(scr, swipe_cb, LV_EVENT_PRESSING, NULL)`；
   挂在 `lv_indev_add_event_cb()` 上收不到 PRESSING（只有 PRESSED/RELEASED 会来）。
2. **滑动松手时 LVGL 还会补发一个 `LV_EVENT_CLICKED`**，发给"按下时那个控件"。
   不处理会出现奇怪现象：*右滑返回后，松手正好落在菜单项上，于是又进了秒表页*；
   或 *左滑时被当成点击，秒表被开始/暂停了一次*。
   解决：滑动一触发就把 `s_sw_done` 置 1，所有"点击"回调先检查它，是假点击就忽略。
   （`lv_indev_stop_processing()` 拦不住这个点击！）
3. 根页面要有"边界"：`page_manager_pop()` 在栈深度 1 时直接返回；
   表盘上滑动时吞掉假点击，但不做任何页面切换。
4. 屏幕模块 **PWR 脚必须接 3V3**，否则整屏全黑（排查了很久）。
5. 触摸方向和屏幕不一致时，改 `touch.c` 里 `esp_lcd_touch_config_t.flags` 的
   `swap_xy / mirror_x / mirror_y` 三个开关。**这块屏实测 Y 方向是反的**
   （点屏幕上边，程序收到下边的坐标），所以现在 `mirror_y = 1`。
   症状就是"点一个地方，响应的却是另一个地方"，特别容易怀疑是自己点偏了。
6. 串口抓日志可以不开 monitor，用脚本抓（见下面"常用命令备忘"），
   `idf.py flash` 之前要确认没有别的程序占着串口（否则报错 failed）。

## 低功耗（✅ 2026-09-29 已上板验证：睡着→触摸唤醒→定时心跳 循环稳定）

> **状态**：`power_mgr.c` 已写完、编译通过，固件 v1.2 也生成并放到 OTA 服务器目录了。
> 但当时板子从电脑上被拔掉（COM8 消失），所以"烧录 + 看日志验证"这步还没做：
> ① 板子插回来后直接 `idf.py -p COMx flash`；或 ② 手表上点 OTA 升级（服务器已是 v1.2）

代码在 `main/power_mgr.c`：

- **15 秒没有触摸/按键** -> 熄屏（LCD 黑屏 + 面板睡眠）+ 关状态灯 + `esp_light_sleep_start()`
- **唤醒源**：触摸 INT（GPIO7）/ BOOT 键（GPIO0）/ 60 秒定时（防止"睡死"，也方便看日志）
- **睡醒保护**：醒来 0.6 秒内的触摸/按键只用来"点亮屏幕"，不执行操作（不会睡醒就误进菜单）
- **OTA 升级期间**：`power_mgr_keep_awake(true)` 禁止睡眠（不然下载会被打断）
- 时间照常走：light sleep 期间芯片内部 RTC 继续计数，醒来时间是对的

实测日志：`空闲 15 秒：熄屏 + 进入 light sleep` -> `已唤醒（原因: 定时器）` -> 循环。

**踩过的两个大坑（面试讲这个很有料）**：
1. **不要在低功耗初始化里 `gpio_config()` 重配触摸的 INT 引脚！**
   触摸驱动是用 INT 中断触发读坐标的，重配 GPIO 会把它的中断关掉，
   表现就是"睡了之后再也点不动"（其实一开机触摸就废了）。
   正确做法：只 `gpio_wakeup_enable()` + `gpio_sleep_set_pull_mode()` 保持上拉。
2. **熄屏不要给 ST7789 发 `sleep in`**：显存内容会丢，醒来一片白，而 LVGL 不知道要重画。
   只发 `disp_on_off(false)`（关显示输出）即可，显存保留；唤醒后再 `lv_obj_invalidate()`
   + `lv_refr_now()` 强制重画一次更保险。
3. 睡觉前先**拿住 LVGL 锁**（`display_lock`）：保证没有 SPI 刷屏 / I2C 读触摸在半路，
   否则那次事务会永远等不到完成，任务挂死。
4. **不要在低功耗任务里调 `lv_refr_now()` 强制重画**：LVGL 整屏渲染很吃栈，
   低功耗任务栈不够会直接"栈溢出重启"。正确做法：只 `lv_obj_invalidate()` 标记失效，
   让专门跑 LVGL 的大栈任务自己重画（几毫秒后就画好了）。

⚠️ **开发板上电流降不到 1mA 级，原因都在硬件**（面试被追问时就这么答）：
1. 屏幕背光是 PWR 脚**直连 3V3**，软件关不掉（几十 mA）-> 要省电得改成 GPIO + MOS 管控制背光
2. 板载 USB 串口芯片、LDO 的静态电流
3. 想验证真实功耗：usb 电流表 / 电池供电 + 万用表测（不能只看软件）

## OTA 在线升级（✅ 2026-09-29 实测通过）

原理见 `partitions.csv`（A/B 双槽）；代码在 `main/ota_update.c`。

```powershell
① 改版本号          main\watch_version.h:  "1.3" -> "1.5"
② 编译              idf.py build
③ 拷固件到服务器     copy build\esp32s3_watch.bin D:\esp32\ota_server\
   同时更新服务器上的版本号（手表拿它和自己的版本比）：
   Set-Content D:\esp32\ota_server\version.txt -Value 1.5 -NoNewline -Encoding ascii
④ 开 HTTP 服务器     cd D:\esp32\ota_server ; python -m http.server 8000
   （第一次会弹 Windows 防火墙，点"允许"）
⑤ 手表：表盘 -> 菜单 -> About -> CHECK UPDATE
   -> 没新版显示"已是最新版本"；有新版才显示 UPDATE 按钮
   -> 点 UPDATE 才真的升级（两步确认，防误触）
⑥ 升级完自动重启 -> About 页看版本号变了 = 成功
```

- **防误触设计**（用户要求）：
  1. OTA 不在主菜单里，收进 About 页的"CHECK UPDATE"
  2. 检查到"和本机版本一样"时，**根本没有可点的升级按钮**
  3. 有新版也要用户再点一次 UPDATE 才开始下载
  4. 升级中/检查中重复点击会被忽略

- 下载地址：`idf.py menuconfig -> Watch 手表配置 -> OTA 固件下载地址`
  （默认 `http://192.168.1.174:8000/esp32s3_watch.bin`，IP 是电脑的局域网 IP，用 ipconfig 查）
- 实测日志：
  `Writing to <ota_1> partition at offset 0x220000`（写另一块槽）
  -> 重启 `Loaded app from partition at offset 0x220000` + `固件 v1.1` + `OTA 新固件确认可用`
- 回滚保险：`CONFIG_BOOTLOADER_APP_ROLLBACK_ENABLE=y`；新固件启动后由 `watch_main.c` 确认可用，
  如果新固件起不来（或忘了确认），bootloader 会自动退回旧版本 —— 不会变砖
- 面试加分点：为什么不能写自己正在跑的分区 / 断电了怎么办 / 怎么写坏也不怕（A/B 双槽）
- 正式产品还要加：HTTPS（服务器证书）+ 固件签名（防止假固件）
