# ESP32 手表小程序（微信）

配套固件工程：`D:\esp32\watch\esp32s3_watch`（手表端蓝牙服务在 `main/ble_watch.c`）

## 你只需要做两步

1. **注册小程序账号**（免费，个人主体可以）
   https://mp.weixin.qq.com -> 立即注册 -> 小程序 -> 拿到 **AppID**
2. **下载微信开发者工具（Windows 版）**
   https://developers.weixin.qq.com/miniprogram/dev/devtools/download.html

然后：开发者工具 -> 导入项目 -> 目录选 `D:\esp32\watch\watch_mp` -> AppID 填你的（或点"测试号"）
-> 编译，就能在模拟器里看到界面；点右上角**"预览"**生成二维码，**手机微信扫码就能用** ✓

## 三个页面

| 页面 | 功能 |
|---|---|
| 数据 | 连接手表（BLE）-> 读步数 / 电量 / 固件版本 / 运行时间 + 日志 |
| 升级 | 选固件文件（.bin）-> 蓝牙传给手表（进度条 + 手表回传进度）|
| 关于 | 项目介绍 + 蓝牙 UUID 对照表 + 小程序更新机制说明 |

## 一键升级（自动检查 + 自动下载 + 蓝牙传输）✅

流程（用户什么都不用选）：
```
进"升级"页 -> 读手表版本 -> 问服务器最新版本 -> 对比
   ├─ 一样   -> "✓ 已是最新版本"
   └─ 不一样 -> "🆕 发现新固件 vX" -> 点"立即升级"
              -> 自动下载固件 -> 蓝牙传手表 -> 手表重启 ✓
```

固件来源：电脑上的 HTTP 服务器目录 `D:\esp32\watch\ota_server`
（由 `D:\esp32\watch\esp32s3_watch\tools\publish.bat` 自动同步 version.txt + bin）
地址写在 `utils/fw.js` 的 `SERVER`（默认 `http://192.168.1.174:8000`，IP 变了要改）

### 让手机/工具能访问网络（关键设置）

| 环境 | 设置 |
|---|---|
| 开发者工具（模拟器） | 详情 → 本地设置 → 勾选 **"不校验合法域名、web-view、TLS 版本及 HTTPS 证书"** |
| 手机上的开发版/体验版 | 小程序后台 → 开发管理 → 开发设置 → 打开 **"开发环境不校验请求域名及 TLS 版本"**（⚠️ 需要正式注册的小程序；**测试号没有这个设置**，所以手机上要自动升级必须注册账号） |
| 正式版 | 换成**微信云开发**（固件放云存储，不用域名不用备案，手机在哪都能用） |

### 电脑端准备（每次发布固件）

```powershell
① 双击 D:\esp32\watch\esp32s3_watch\tools\publish.bat     # 编译 + 发布 + 同步 version.txt
② cd D:\esp32\watch\ota_server ; python -m http.server 8000   # 起服务器（第一次防火墙点"允许"）
③ 手机和电脑连同一个 WiFi
```

## 你要的"打开时提示新版本，是否更新"

已经在 `app.js` 里用微信官方机制实现了：

```js
const um = wx.getUpdateManager()
um.onUpdateReady(() => {
  wx.showModal({ title:'发现新版本', content:'是否重启应用？',
    success: r => r.confirm && um.applyUpdate() })
})
```

> 微信每次打开小程序都会自动检查新版本；你上传发布新版本后，
> 用户端一般 24 小时内会收到（官方机制，无需自己做服务器）

## 固件发布 + 自动检查新固件（已实现）

电脑上双击 **`D:\esp32\watch\esp32s3_watch\tools\publish.bat`**：
```
· idf.py build 编译
· 自动复制到 D:\esp32\watch\fw_release\esp32s3_watch_v<版本号>.bin（旧的 .bin 删掉）
· 顺便同步 WiFi-OTA 服务器目录（version.txt = 新版本）
```

小程序"升级"页每次打开会：读手表版本 → 和本地固件的版本（从文件名 `..._v1.7.bin` 解析）
对比 → 不一样就显示绿色横幅"🆕 发现新固件 v1.7（手表现在 v1.6）"，
按钮变成"立即升级到 v1.7" ✓；一样则显示"✓ 手表已是最新版本" ✓

## 蓝牙对接（对应固件 ble_watch.c）

```
0xFF00 服务
0xFF01 读        固件版本
0xFF02 读+通知   状态数据 "fw=1.6;up=123s;step=0;bat=--"
0xFF03 写        命令 "reboot"
0xFF04 写        固件数据：先 4 字节小端总长度，再按块传
```

**传输速度**：官方建议每次写入 ≤20 字节（iOS 不支持加大 MTU）。
- Android：自动协商 MTU 512，用 240 字节/包，约几分钟
- iOS：20 字节/包，1.8MB 大约 10~20 分钟（传输时别切出去）

> 想要快：手表本身还有 **WiFi OTA**（20 秒），以后可以在小程序里加
> "让手表连 WiFi 直接下载"的流程（BLE 只负责下发 WiFi 密码）。
