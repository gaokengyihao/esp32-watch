# ESP32-S3 使用说明（从 STM32 + Keil 转过来）

## 0. 一句话概括

ESP32 不用 Keil，也不用 J-Link/ST-Link。开发流程是：

```
改代码  ──►  idf.py build  ──►  idf.py -p COMx flash  ──►  idf.py -p COMx monitor
          （相当于"编译"）      （一根 USB 线下载）          （相当于串口助手）
```

## 1. 和 STM32 的对照

| 事项         | STM32（Keil）          | ESP32-S3（ESP-IDF）                  |
| ------------ | ---------------------- | ------------------------------------ |
| 开发软件     | Keil MDK               | 命令行 PowerShell（或 VS Code 插件） |
| 编译         | Build（F7）            | `idf.py build`                       |
| 下载         | ST-Link/J-Link 下载器  | 芯片自带 USB 下载，一根 USB 线即可   |
| 看串口打印   | 串口助手 / XCOM        | `idf.py monitor`（也可用 ATK-XCOM）  |
| 程序入口     | `int main(void)`       | `void app_main(void)`                |
| 外设库       | HAL 库                 | ESP-IDF driver 组件（`driver/gpio.h` 等） |
| 图形化配置   | Keil 的配置向导        | `idf.py menuconfig`                  |

> `app_main()` 相当于 STM32 的 main，但它运行在一个 FreeRTOS 任务里；
> 函数返回后任务会被删除，所以死循环类程序要自己写 `while(1)`。

## 2. 每次开发的固定流程

1. 双击桌面上的 **`IDF_v6.1-beta1_Powershell`** 快捷方式（会自动配好 ESP-IDF 环境）
2. 进入工程目录：

   ```powershell
   cd E:\esp32\project\测试\esp32s3_test
   ```

3. 用任意编辑器改代码：`main\esp32s3_test.c`
4. 编译：

   ```powershell
   idf.py build
   ```

5. 插上开发板的 USB 线，看设备管理器里新增的 COM 号（"端口 (COM 和 LPT)"下面）
6. 烧录 + 打开串口（一条命令全搞定）：

   ```powershell
   idf.py -p COM3 flash monitor
   ```

   （把 COM3 换成你实际的串口号；`monitor` 里按 **Ctrl + ]** 退出）

## 3. 常用命令

| 命令                       | 作用                             |
| -------------------------- | -------------------------------- |
| `idf.py menuconfig`        | 图形化配置工程（类似 Keil 选项） |
| `idf.py build`             | 只编译                           |
| `idf.py -p COM3 flash`     | 只烧录                           |
| `idf.py -p COM3 monitor`   | 只看串口                         |
| `idf.py fullclean`         | 清掉编译结果，彻底重编           |
| `idf.py -p COM3 erase-flash` | 擦除整块 Flash（芯片救砖用）    |

## 4. 下载/打印 出问题怎么排查

| 症状                                       | 处理                                                        |
| ------------------------------------------ | ----------------------------------------------------------- |
| 设备管理器里没有新增串口                   | 换板上另一个 USB-C 口试试（很多 S3 板有两个：UART 口和 USB 口）；或者装 CH340 驱动 |
| 报错 `Failed to connect ... No serial data received` | 按住 **BOOT** 键不放 → 点一下 **RST/EN** 键 → 松开 BOOT，再重新执行烧录命令 |
| 烧录成功但串口没打印                       | 确认打开的是正确的 COM 口、波特率 115200                    |
| 串口里全是乱码                             | 波特率不对，改成 115200                                     |

> 本机已安装 CH341 驱动，常见的 CH340 USB 转串口板子可以直接用。

## 5. 当前工程说明

- 目标芯片：**esp32s3**，按 **N16R8** 配置（16MB Flash + 8MB Octal PSRAM）
- 程序功能：开机打印芯片型号/Flash/PSRAM/内存信息，然后板载 RGB 灯每秒循环
  **红 → 绿 → 蓝 → 灭**，同时在串口打印状态
- 板载 RGB 灯（WS2812）常见引脚：GPIO48（DevKitC-1 v1.0）或 GPIO38（v1.1 / 多数 N16R8）；
  程序**同时驱动这两个脚**，哪个灯亮说明你的板子用哪个，对板子无副作用
- 工程文件结构：

  ```
  esp32s3_test/
  ├─ CMakeLists.txt          # 工程名等，一般不用改
  ├─ sdkconfig              # 编译配置（menuconfig 保存的）
  ├─ sdkconfig.defaults     # 默认配置（16MB Flash / PSRAM 在这里设的）
  ├─ main/
  │  ├─ CMakeLists.txt      # 源文件清单
  │  └─ esp32s3_test.c      # ← 你的代码写这里
  └─ build/                 # 编译输出，删掉会自动重建
  ```

## 6. 可选：VS Code 图形化开发（更接近 Keil 的体验）

1. VS Code 安装扩展 **ESP-IDF**
2. 扩展里选择 `Existing ESP-IDF Installation`，路径填 `C:\esp\v6.1-beta1\esp-idf`
3. 之后就可以在底部状态栏点 🔨 编译、⚡ 烧录、📺 串口监视
